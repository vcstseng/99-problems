01

我們的 Consulting Agent Framework

依問題組合專業能力，沿用共通的解題與審查流程。需要 AI 才用 AI；計算、規則或流程改善足夠時，就用更合適的方法。

Agents · Skills · Tools

Agents 協調與承接工作，Skills 提供領域知識與顧問方法，Tools 執行受限資料查詢、計算與查核。

Security · Governance

限定資料與工具範圍、保留證據與版本、設置審查及停止關卡。人保留責任與決策權。

能力如何逐步建立？

99 題已有候選能力對應，部分已實作；邏輯角色不等於獨立模型，技能規格也不等於已驗證能力。每一題仍需確認資料、方法與專業適用性。

02

從問題到顧問方案

釐清問題 → 調查分析 → 證據查核 → 方案比較 → 管理審查 → 顧問交接。

交付包含問題診斷、分析證據、推薦理由、執行路線、責任分工、資源假設與驗收條件。缺資料時，明列假設、限制及下一步調查，不把推測寫成結論。

人與 Agent 如何協作？

Agent 準備分析與建議；管理者可以補證據、退回修改、接受有界交付，或拒絕／停止。每次修訂重新驗證，決策綁定對應版本。真實責任人決定目標、預算、風險與是否實施。

目前管理指示與審查由同一助手模擬，並非使用者核准或獨立專家評閱。顧問團隊提供方案與導入規劃，現階段不承接客戶軟體開發、部署或現場變更。

03

讓建議可檢查、可追溯、可停止

對客戶而言，重要的不只是答案，還包括資料如何使用、結論從何而來，以及誰保留決策權。框架以限定資料與工具範圍、證據查核及版本紀錄支援這些要求；有疑問可以追問、退回或停止，接受分析不等於授權實施。

目前有哪些控制與限制？
  • 原型會核對來源版本、保存分析與審查紀錄、接續已保存案件，並阻止把舊決策套用到新內容。
  • 展示使用合成資料與模擬身份；企業身份與存取管理、獨立專家評閱及真人操作體驗仍待驗證。
  • 本網站呈現顧問成果，不會即時執行 Agent 或替企業採取行動。

2026-10-27 里程碑：三類既有能力，換個簡單情境再驗證

凍結能力、先訂標準，再執行相近情境；不刻意增加問題難度。遇到失敗就保留原因，修正與重測分開記錄。

  • CS02 值班工單：直接重用 2/2；轉人工／到期停止 2/2。未解結果不能接受，停止後重開仍有效。
  • E93 供應商評估：直接重用 2/2；缺來源停止 1/1。保留反對與未知，來源改動攔截舊結果。
  • CS07 新產品客服：直接重用 2/2；授權／有效性／歧義拒答 4/4。版本與權限限制持續成立。

這是三個合成情境的相關條件，不是十三次獨立遷移試驗或新增解決十三題。正確停止／拒答不算解題成功。同一助手編製與檢查、Mock Lead 與確定性 Worker，尚未證明自主 Agent 或真實業務成效。沒有新增引擎能力或 Planner，正式 Problem X 保留；案例成熟度與總數不變。

同日後續里程碑：F03 簡單成本情境

包裝產品成本重用測試完成：計算／資料列順序檢查 2/2；缺價格／竄改總額控制 2/2。差異 1,180 可核對為產量 700、材料價格 480，來源變更後舊結果失效。

新增的是第四類既有能力的重用證據，不是新解決一題，也不是自主學習或因果證明。沒有修改引擎能力、提高問題難度或新增 Planner。完成 docs 與雙語網站更新後，停在這個里程碑。

怎麼解讀驗證結果？

原型已對計算、證據版本與審查紀錄進行自動檢查，但這不等於商業成效，也不能取代真人操作與專家評閱。文件完整與問題在現場解決，仍是不同的里程碑。
