SC03 供應鏈

品質開始變差，到底是哪家供應商、哪批料或哪個製程出了問題？

品質異常可能跨越Supplier、Material Lot、Production Lot與Process Conditions，企業即使知道Defect或RMA正在增加，也難以沿著Lot Genealogy快速縮小受影響範圍並找出值得優先驗證的候選根因

01

問題是什麼？

品質異常可能跨越Supplier、Material Lot、Production Lot與Process Conditions，企業即使知道Defect或RMA正在增加，也難以沿著Lot Genealogy快速縮小受影響範圍並找出值得優先驗證的候選根因

02

需要知道什麼？

品質變差時，要沿著供應商、物料批次、生產批次、製程參數、良率、Defect 與 RMA 一路追，才能知道異常影響範圍。單看某個報表，很難分辨是哪一批料、哪個製程或哪個供應商共同造成。

主要資料

Supplier、Material/Production Lot Genealogy、進料檢驗、良率、製程參數、Defect、RMA/DOA與Failure Reports

既有系統

QMS、MES、ERP、PLM

03

AI 改變了什麼？

在具備可靠Lot Genealogy的前提下，AI/ML可跨Supplier、Lot、Process與Failure Data辨識多變量異常與共同模式，LLM可解析RMA/Failure Reports；模型只能排序候選根因，不能把統計關聯直接視為因果。

04

怎麼解？

先利用 Lot Genealogy 縮小受影響範圍，再把進料、製程、Defect 與售後失效資料一起分析。系統排序最值得做 Failure Analysis 的供應商、批次與製程候選根因，讓工程驗證更快。

Solution Core

Lot Genealogy Analysis + Quality Anomaly Detection + Multivariate Root-Cause Ranking + Failure Report Intelligence

05

AI 做什麼？

沿Material與Production Lot追蹤品質異常的影響範圍，結合進料、製程、Defect與RMA資料尋找共同條件與異常模式，並排序最值得進一步Failure Analysis的Supplier、Lot與Process候選根因

06

人決定什麼？

SQE、Quality與Engineering驗證候選根因、執行Failure Analysis與必要實驗，決定Containment、停料、退料、Supplier Corrective Action或製程改善

07

最後改善什麼？

縮短從發現品質劣化到定位受影響批次與候選根因的時間，降低Defect、RMA、報廢與品質問題持續擴散的風險
