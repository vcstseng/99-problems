E95 系統性後果

如果 AI 的預測會改變人的行動，那最後看到的證據會不會只是自己影響出來的結果？

預測系統會影響資源配置與人的行動，而這些行動又會改變後續結果與訓練資料，形成「預測 → 行動 → 結果 → 再學習」的閉環。久而久之，模型可能把自己介入造成的結果，誤認成對世界本來樣子的準確描述。

01

問題是什麼？

預測系統會影響資源配置與人的行動，而這些行動又會改變後續結果與訓練資料，形成「預測 → 行動 → 結果 → 再學習」的閉環。久而久之，模型可能把自己介入造成的結果，誤認成對世界本來樣子的準確描述。

02

需要知道什麼？

當模型分數會改變誰被接觸、誰拿到資源、誰看到推薦時，後來觀察到的 Outcome 已經不是自然發生。要把 Prediction、Downstream Action、Exposure／Treatment、Outcome、Training Data 和版本一起追蹤。

主要資料

Predictions、Scores、Downstream Actions、Resource Allocation、Exposure／Treatment、Outcomes、Training Data、Model Versions

既有系統

CRM、Recommendation Engine、Decision System、Experiment Platform、ML Logs

03

AI 改變了什麼？

一般預測往往假設觀察到的結果主要來自外部世界；但當模型本身決定誰得到機會、曝光或服務時，資料生成機制已經被模型改變。AI/ML 可以協助偵測回饋循環，但要區分預測與介入效果，仍需要因果方法。

04

怎麼解？

建立 Feedback Loop 追蹤，區分自然結果和模型介入後造成的結果。透過 Holdout、Exploration、反事實評估或因果分析，檢查模型是不是正在用自己影響出來的資料證明自己。

Solution Core

Feedback-Loop Detection + Exploration Policy + Counterfactual / Causal Evaluation

05

AI 做什麼？

追蹤預測如何影響後續行動，區分自然發生的結果與模型介入後的結果，利用保留組、探索機制、反事實評估或因果分析，檢查模型是否正在用自己造成的結果驗證自己。

06

人決定什麼？

決定哪些情境必須保留探索樣本、哪些族群不能只依分數分配機會，以及何時需要刻意打破模型形成的回饋循環。

07

最後改善什麼？

降低模型把自身介入結果誤認成客觀證據的風險，保留發現錯誤假設的機會；無法完全消除回饋循環，但可以刻意保留反事實比較。
