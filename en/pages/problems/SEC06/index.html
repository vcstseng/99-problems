SEC06Security

If one agent is compromised, can the problem spread through the rest of the agent network?

Agents can delegate tasks, share memory, and trust each other's messages, allowing one compromised agent to influence others through normal collaboration paths.

01

What's the problem?

Agents can delegate tasks, share memory, and trust each other's messages, allowing one compromised agent to influence others through normal collaboration paths.

02

What do we need to know?

Map agent identities, delegation relationships, message provenance, shared memory, tool permissions, and explicit trust boundaries.

Key inputs

Agent identities, messages, delegation graph, message provenance, shared memory, tool permissions, trust relationships

Existing systems

Agent platform, message bus, IAM, MCP

03

What does AI change?

Multi-agent systems create propagation paths similar to distributed trust systems. Containment depends on isolation, provenance, and least privilege between agents.

04

How do we solve it?

Give agents distinct identities and scopes, authenticate inter-agent messages, limit shared state, and contain propagation when one agent becomes suspicious.

Solution Core

Agent Isolation + Explicit Trust Boundaries + Message Provenance + Least Privilege + Propagation Containment

05

What does AI do?

Operate within explicit trust boundaries and carry provenance with delegated tasks and messages.

06

What do people decide?

Design the trust graph, define isolation requirements, and manage incident containment.

07

What improves?

Reduce the blast radius of a compromised or malicious agent.

How does the agent framework approach this problem?

Start with the decision and evidence needs, then combine consulting skills and approved tools under human review, security and governance. The framework defines the approach; this page alone does not establish implemented capability or proven results for this problem.
