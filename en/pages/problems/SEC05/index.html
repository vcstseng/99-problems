SEC05Security

If AI remembers something wrong once, can that bad memory keep becoming 'true'?

Persistent agent memory can preserve false, outdated, or malicious information and repeatedly reintroduce it into future decisions.

01

What's the problem?

Persistent agent memory can preserve false, outdated, or malicious information and repeatedly reintroduce it into future decisions.

02

What do we need to know?

Track every memory record with source, trust level, identity, timestamp, write event, version, and relationship to authoritative knowledge sources.

Key inputs

Memory records, conversation history, source provenance, trust level, user identity, timestamps, write events, RAG stores, knowledge sources

Existing systems

Vector DB, knowledge base, agent memory, DMS

03

What does AI change?

Long-term memory makes errors durable. Reliable memory therefore needs provenance, write controls, expiry, versioning, and quarantine rather than treating every model-generated fact as permanent.

04

How do we solve it?

Gate what can be written to memory, preserve source lineage, expire or version uncertain content, and quarantine suspicious writes until reviewed.

Solution Core

Memory Provenance + Trust-Based Write Gates + Versioning + Expiration + Quarantine

05

What does AI do?

Propose memories and retrieve prior context, while carrying source and trust metadata forward.

06

What do people decide?

Define what is worth remembering, which sources are authoritative, and when disputed memory must be corrected or removed.

07

What improves?

Keep persistent memory useful without allowing one bad inference to contaminate future work indefinitely.
