E93System Effects

If ten AIs give the same answer, is that really ten independent judgments?

Multiple agents can appear to agree while sharing the same model, sources, prompts, assumptions, or upstream analysis, turning duplicated evidence into fake consensus.

01

What's the problem?

Multiple agents can appear to agree while sharing the same model, sources, prompts, assumptions, or upstream analysis, turning duplicated evidence into fake consensus.

02

What do we need to know?

Track model IDs, prompts, retrieved sources, assumptions, upstream analyses, and decision records behind every recommendation.

Key inputs

Agent outputs, model IDs, prompts, retrieved sources, upstream analysis, assumptions, decision records

Existing systems

Agent platform, LLM gateway, RAG, data catalog, decision logs

03

What does AI change?

Multi-agent agreement is meaningful only when the evidence and reasoning paths are genuinely diverse enough to count as independent signals.

04

How do we solve it?

Build a dependency map for recommendations and distinguish true convergence from answers that inherit the same source or upstream assumption.

Solution Core

Decision Provenance + Dependency Mapping + Diversity Controls

05

What does AI do?

Trace observable provenance and identify common dependencies across apparently independent outputs.

06

What do people decide?

Decide when a decision requires genuinely independent evidence and deliberately introduce different methods or sources.

07

What improves?

Reduce common-mode epistemic failure and stop duplicated signals from masquerading as independent confirmation.

08

Experiment: agreement is not independent evidence

A bounded source-dependency audit passed; autonomous agent-team ability remains unproven. Ten synthetic reports agree, but each traces through a repost and summary to one primary source. Ten reports are not ten independently supported judgments.

10 reports → shared repost and summary → 1 declared primary source

The audit traces source relationships and preserves uncertainty. Even distinct roots do not prove statistical independence or truth.

What failed, and what changed?

The unchanged original tool registry rejected the required dependency audit. That failure was retained. A bounded lineage tool and a separately implemented checker were added, then retested under the same frozen process and criteria.

09

Test the process, not just the answer

Freeze the brief and criteria → check readiness → analyze → challenge → reverify → decide on the exact version → deliver with limits. Missing evidence stops progress; changes to the criteria invalidate the run rather than rescuing a failure.

Checks and evidence

Eight synthetic scenarios cover shared and separate roots, upstream reports, contradictory evidence, missing sources, cycles, instruction text and unrelated sources. Twenty-five new checks and 249 total regression checks passed. These are software/process checks, not independent-model or business-outcome validation.

Gate tests cover review returns and retry limits, stale decisions, durable stop and changed sources. The main accepted run used one analysis version; it did not itself need a revision. The review-return path was separately tested.

Experiment and limitations (JSON) · Synthetic lineage source · Frozen acceptance protocol

Analysis used deterministic tools; role review was performed by the same assistant. It was not a blinded experiment or multiple isolated AI agents challenging each other. Hidden dependencies, independent reasoning, real-world truth and commercial outcomes remain unproven.

A simple new context: supplier-review evidence

2026-10-27: two direct-reuse conditions passed; one missing-source stop met expectations.Of three reviews, two trace back to the same supplier log and one cites opposing evidence. Existing tools preserve the shared source and opposition without treating three reports as three independent judgments. Missing position labels remain unknown; a missing underlying source requires evidence.

Process controls, evidence and limits

Changing a source after submission prevents acceptance of the old proposal. Capabilities stayed frozen, with one attempt per condition, no engine changes and no external model calls. The same assistant authored and reviewed this synthetic context. It is not blind evaluation, formal Problem X or full seven-gate validation. It does not decide supplier suitability, establish source truth or find hidden dependencies. A correct stop is not a solved problem.
