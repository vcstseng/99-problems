E93System Effects

If ten AIs give the same answer, is that really ten independent judgments?

Multiple agents can appear to agree while sharing the same model, sources, prompts, assumptions, or upstream analysis, turning duplicated evidence into fake consensus.

01

What's the problem?

Multiple agents can appear to agree while sharing the same model, sources, prompts, assumptions, or upstream analysis, turning duplicated evidence into fake consensus.

02

What do we need to know?

Track model IDs, prompts, retrieved sources, assumptions, upstream analyses, and decision records behind every recommendation.

Key inputs

Agent outputs, model IDs, prompts, retrieved sources, upstream analysis, assumptions, decision records

Existing systems

Agent platform, LLM gateway, RAG, data catalog, decision logs

03

What does AI change?

Multi-agent agreement is meaningful only when the evidence and reasoning paths are genuinely diverse enough to count as independent signals.

04

How do we solve it?

Build a dependency map for recommendations and distinguish true convergence from answers that inherit the same source or upstream assumption.

Solution Core

Decision Provenance + Dependency Mapping + Diversity Controls

05

What does AI do?

Trace observable provenance and identify common dependencies across apparently independent outputs.

06

What do people decide?

Decide when a decision requires genuinely independent evidence and deliberately introduce different methods or sources.

07

What improves?

Reduce common-mode epistemic failure and stop duplicated signals from masquerading as independent confirmation.
