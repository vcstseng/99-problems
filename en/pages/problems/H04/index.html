H04HR

What capability is this person really missing, and what should they learn next?

Development plans are often generic because performance, project evidence, skills, and learning history are not connected into a clear capability gap.

01

What's the problem?

Development plans are often generic because performance, project evidence, skills, and learning history are not connected into a clear capability gap.

02

What do we need to know?

Link role capability models with actual work evidence, project outcomes, assessments, performance, learning history, and a consistent skill taxonomy.

Key inputs

Role capability model, resume/experience, projects and work outcomes, performance, assessments, learning history, skill taxonomy

Existing systems

HRIS, LMS, performance management, project systems

03

What does AI change?

AI can map messy evidence to a skill model and suggest adjacent development paths, but it should not infer capability from titles alone.

04

How do we solve it?

Build an evidence-based skill profile, identify the gap to the target role or task, and recommend the smallest useful development step.

Solution Core

Skill Evidence Mapping + Skill Gap Analysis + Development Recommendation

05

What does AI do?

Extract skill evidence, map it to the taxonomy, and recommend learning or assignments that close the highest-value gaps.

06

What do people decide?

Validate capability judgments, define the target role, and decide which development opportunities are realistic.

07

What improves?

Make development more specific, relevant, and connected to real work.
